# PMSM FOC 전류제어 (dq 변환 & 전류 PI 제어기)

## 핵심 요약

PMSM 벡터 제어(FOC)의 기초가 되는 dq 변환의 역사·원리와, 전류 루프를 구성하는 PI 제어기 + Feed-Forward 디커플링의 구체적인 설계 과정을 정리.

## dq 변환과 벡터 제어의 역사

- **Clarke 변환(αβ 변환)**: Edith Clarke가 1937~38년 논문으로 발표. 3상 교류 파형을 2상 교류 파형으로 변환.
- **Park 변환**: Robert H. Park가 1929년 고안. 2상 교류 파형을 2상 직류 파형으로 변환.
- **dq 변환 = Clarke 변환 × Park 변환**.
- 변환 이론 자체는 100년 가까이 전에 정립되었지만, 이를 이용한 벡터 제어(FOC)는 1970년대에야 개발되었고 1980년대 마이크로프로세서 발전과 함께 상용화됨.
- dq 변환의 핵심 효과: 자속(d축)과 토크(q축)를 독립적으로 제어할 수 있게 되어 고속·정밀 제어, 회전자 위치추적, 운전성능 극대화가 가능해짐.

## FOC vs DTC

- **벡터 제어(FOC)**: 3상 전류를 dq 좌표계로 변환해 직류화 → 자속 전류(id)와 토크 전류(iq)를 독립 제어 → 다시 3상으로 변환해 고정자 코일로 인가.
- **직접 토크 제어(DTC)**: 전류 루프 없이 자속·토크를 전압/전류 측정값으로부터 실시간 추정 → 히스테리시스 비교기로 허용범위 이탈 여부 판단 → 스위칭 테이블 기반으로 인버터 상태 직접 선택. 구조는 단순해 보이나 히스테리시스 제어로 인한 급격한 스위칭 변화 때문에 토크 리플, 고속 영역 효율저하, 고조파 문제, 높은 센서 의존성을 동반 → 실무에서는 FOC가 더 널리 쓰임.

## 전류 PI 제어기 설계

### 전체 제어 흐름

```
Id*, Iq* → (오차) → Current PI Controller → Vd*, Vq*
  → Inverse Park → Vα, Vβ → SVPWM → Va,Vb,Vc PWM → 3상 인버터 → Ia,Ib,Ic
  → Clarke + Park → Id, Iq Feedback (루프)
```

### PMSM dq축 전압방정식

$$V_d = R_s i_d + L_d\frac{di_d}{dt} - \omega_e L_q i_q$$
$$V_q = R_s i_q + L_q\frac{di_q}{dt} + \omega_e L_d i_d + \omega_e \lambda_f$$

저항 성분·인덕턴스 성분·교차결합(Cross Coupling)·Back EMF, 총 4개 성분으로 구성됨 (Rs: 고정자 저항, Ld/Lq: d/q축 인덕턴스, λf: 영구자석 자속, ωe: 전기각속도).

### PI 제어 + Feed-Forward 디커플링

오차: $e_d = i_d^*-i_d$, $e_q = i_q^*-i_q$

PI 출력: $u_d = K_{pd}e_d+K_{id}\int e_d dt$, $u_q = K_{pq}e_q+K_{iq}\int e_q dt$

PI만으로는 dq축이 서로 간섭하므로 Feed-Forward로 디커플링:

$$V_d^*=K_pe_d+K_i\int e_ddt-\omega_eL_qi_q$$
$$V_q^*=K_pe_q+K_i\int e_qdt+\omega_eL_di_d+\omega_e\lambda_f$$

즉 PI가 오차를 제거하고 Feed-Forward가 모델(교차결합·Back EMF)을 보상하는 구조 — 실제 서보드라이브 대부분이 이 구조를 사용.

### 디지털(이산시간) 구현

$$I_d(k)=I_d(k-1)+K_iT_se_d(k)$$
$$V_d(k)=K_pe_d(k)+I_d(k)-\omega_eL_qi_q$$
$$V_q(k)=K_pe_q(k)+I_q(k)+\omega_eL_di_d+\omega_e\lambda_f$$

DSP에서 가장 많이 사용되는 형태.

### 역Park → 역Clarke → SVPWM

$$V_\alpha=V_d\cos\theta-V_q\sin\theta,\quad V_\beta=V_d\sin\theta+V_q\cos\theta$$

(θ = 회전자 전기각)

$$V_a=V_\alpha,\quad V_b=-\tfrac12V_\alpha+\tfrac{\sqrt3}{2}V_\beta,\quad V_c=-\tfrac12V_\alpha-\tfrac{\sqrt3}{2}V_\beta$$

$$Duty_X=\tfrac12+\frac{V_x}{V_{dc}}$$

위 듀티식은 개념적 표현이며, 실제 SVPWM 구현에서는 섹터별 유효벡터 시간 $T_1, T_2$와 영벡터 시간 $T_0$를 계산해 최종 듀티를 생성함.

### 인버터 → 전류 생성 물리

모터 권선은 RL 회로: $L\frac{di}{dt}=V-Ri-E$ (E: 역기전력/Back EMF). 전압이 높을수록 di/dt가 커져 전류가 목표값에 빠르게 수렴.

### 전자기 토크와 제어기 설계 관점

$$T_e=\frac{3}{2}p\left(\lambda_f i_q+(L_d-L_q)i_di_q\right)$$

표면부착형(SPMSM)은 $L_d \approx L_q$이므로 $T_e \approx \frac32 p\lambda_f i_q$ — **q축 전류가 토크를 직접 결정하고, d축 전류는 자속(및 약자속 제어)을 담당**. 전류 루프는 전압을 직접 제어하는 것이 아니라 전압을 조작변수로 사용해 전류를 제어하며, "전류 PI 제어기 → 전압 생성 → PWM → 인버터 → 전류 생성 → 토크 생성"이 FOC 기반 PMSM 제어의 핵심 루프.
