# 외란관측기(Disturbance Observer, DOB) 기반 제어

## 핵심 요약

로봇 매니퓰레이터의 궤적 추종 성능을 높이기 위한 외란관측기(DOB) 기반 제어 논문 요약. 루엔버거 상태관측기로 직접 측정하기 어려운 상태(각속도·각가속도)를 추정하고, 모델 기반 예상 토크와 실제 입력 토크의 차이로 외란을 계산해 보상 토크로 피드백하는 구조.

## 상태 공간 모델 변환

재귀최소자승법(RLS)으로 얻은 관절 모델(전달함수)을 제어하기 쉬운 상태공간 방정식으로 변환:

$$x_i[n+1] = A_i x_i[n] + B u_i[n]$$
$$y_i[n] = q_i[n]$$

$x_i$: 관절의 상태벡터(각도·각속도·각가속도 등), $A_i$: 시스템 행렬, $B$: 입력 행렬.

## 루엔버거 관측기(Luenberger Observer)

$$x_i[n+1] = A_i x_i[n] + B u_i[n] + L_i y_e[n]$$
$$y_e[n] = y_i[n] - \hat{y}_i[n]$$

- $L_i$: 관측기 게인 벡터 — 추정 오차를 빠르게 0으로 수렴시키도록 pole-placement(극점 배치) 방법으로 선정.
- $y_e[n]$: 실제 관측값과 모델 기반 추정값($\hat{y}_i$)의 차이 — 이 오차를 보정함으로써 직접 측정 불가능한 상태 변수(각가속도 등)를 실시간 도출.
- **핵심 목적**: 센서 추가 없이 수학적 모델과 알고리즘만으로 관절 상태 정보를 확보 → 이후 DOB 설계를 위한 필수 기반 데이터 제공.

## 외란(Disturbance) 계산

$$\tau_d[n] = \tau_i[n] - \hat{\tau}_d[n]$$

- $\tau_i[n]$: 실제 관절에 인가된 토크(입력).
- $\hat{\tau}_d[n]$: 로봇의 물리적 모델(질량·댐핑·강성)과 현재 상태(각도·속도·가속도)로 계산한 모델 기반 "예상 토크".
- $\tau_d[n]$: 외란 — 실제 인가 토크에서 모델 예측 토크를 뺀 나머지 힘. 마찰력, 중력 오차, 외부 충격 등 모델에 포함되지 않은 성분이 여기 포함됨.

## 제어 구조 핵심

실시간으로 계산된 외란 값을 제어기에 피드백해 그만큼의 보상 토크를 추가함으로써, 로봇이 외부 환경(마찰·부하 변화 등)에 상관없이 설정된 궤적을 정확히 추종하도록 만드는 것이 이 제어 전략의 핵심.
